## What the run proves

Final validation: 18 tests passed, lint clean, Next.js production build passed with 742 static pages. Desktop/mobile studio inspection showed no captured browser warnings/errors. No external API was called by the tests.

Stable-ID ingestion, grounding validation, repeatable/no-duplicate resume, source/brief/candidate versioning, frozen chapters, visual-diversity plan reporting, local metadata search, permission checks, file compression/hash storage, approval controls, staging exports, and a default-off integration point in the existing app.

Tests additionally exercise the genuine-image lifecycle with synthetic fixtures, API request construction with fake responses, local HTTP saving/conflict protection, and manifest acceptance rules. Those are software tests, not evidence that the paid model produces good art.

## What it does not prove

Watercolor quality/style matching, anatomy, visual relevance, repeated faces/staging, model latency, real request cost, organization-specific emotional tone, or paid API account/model availability. No real vision screening/captioning has run. Perceptual hashes are screening suggestions and are poor at detecting shared character identities. The studio is local and operator-trusted, not a hosted authenticated team service.
