# Reference Guide

## How to use the reference library
The visual files in `references/visuals/` are **directional references**, not pixel-perfect specifications. They were created specifically for this project to communicate hierarchy, density, and product character.

Study them before major UI decisions.

### Visual boards
- `01_landing.svg` - landing-page composition
- `02_match_step.svg` - focused questionnaire step
- `03_interest_cards.svg` - tactile multi-select pattern
- `04_results.svg` - personalized match-results hierarchy
- `05_club_card.svg` - reusable club-card anatomy
- `06_explore.svg` - search + filters + grid
- `07_club_detail.svg` - profile/detail information architecture
- `08_mobile_results.svg` - mobile adaptation
- `09_empty_state.svg` - useful empty state
- `10_loading_state.svg` - skeleton loading
- `11_design_tokens.svg` - palette / type / spacing summary
- `12_involvement_stack.svg` - optional premium recommendation concept
