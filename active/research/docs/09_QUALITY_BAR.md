# Quality Bar

Before declaring the MVP complete, verify:

## Functional
- landing CTAs route correctly
- quiz selections persist between steps
- back button works
- quiz completes without dead ends
- matching returns sensible ordering
- club cards route to the right club
- Explore search works
- filters work or are intentionally disabled/omitted
- external CTA links are safe if present

## Visual
- consistent type hierarchy
- consistent card radius/borders
- cardinal is restrained
- no generic purple gradient aesthetic
- no text clipping
- no strange whitespace or horizontal scroll
- dense content remains readable
- selected/unselected states are unmistakable

## Responsive
Check at least:
- ~1440px desktop
- ~1024px laptop/tablet
- ~390px mobile

## Content
- no lorem ipsum
- no fake quotes presented as real
- no unsupported claims about clubs
- no generic AI marketing filler
- consistent commitment language

## Accessibility
- visible keyboard focus
- buttons are buttons
- form inputs have labels
- sufficient contrast
- step changes do not strand keyboard focus

## Performance / stability
- no obvious console errors
- no broken image loops
- no layout shifts caused by unbounded images
- loading states are deliberate
